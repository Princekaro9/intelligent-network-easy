FIABILITÉ DE L'ANALYSE

Une anomalie n'est pas automatiquement une attaque.

INPA sépare volontairement les informations observées des interprétations et des hypothèses. L'objectif est de produire une analyse compréhensible sans transformer une supposition en certitude.

FAIT OBSERVÉ Ce qui a réellement été capturé.

Exemple : une connexion TCP vers le port 443 a été observée.

INTERPRÉTATION Ce que les données peuvent signifier.

Le port 443 est généralement associé aux communications HTTPS.

HYPOTHÈSE Une possibilité qui doit être vérifiée.

Cette communication pourrait correspondre à un service Web.
