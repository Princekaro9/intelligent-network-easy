# Identité visuelle INPA

- `inpa-background.png` : arrière-plan global de l'application.
- `inpa-splash.png` : écran de démarrage à afficher environ 1–2 secondes.
- `inpa-logo.png` : logo détouré/transparence utilisé dans la navigation, favicon et interfaces.

Les trois éléments doivent conserver une cohérence : noir profond, bleu électrique/cyan, chrome sombre et ambiance cybersécurité.
